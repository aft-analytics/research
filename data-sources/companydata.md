# CompanyData (USA)

[companydata.com/usa](https://companydata.com/usa/) · [pricing](https://companydata.com/pricing/)

Commercial firm file (~65M+ US), sourced from state SOS, SEC, Census, directories. Fields: name, address, EIN/reg #, legal type, NAICS, revenue/employees (often estimated), contacts.

**Limit:** ~$30k / 1M rows → full USA dump impractical. Easier to pull from state SOS (etc.) ourselves for bulk matching; this is at most tiny extracts / lookup.
