# U.S. Title Records

[ustitlerecords.com](https://www.ustitlerecords.com/) — per-property **human title abstractor** service (since 2009), not a national deed dump.

**What you get:** PDF reports emailed after live county/title-plant research. Claims 3,250+ U.S. counties / 50 states. Flat published prices (same for commercial; CSV bulk order; API only on high-volume Custom tier for *order/status/PDF retrieve* — not bulk ownership files).

| Report | Price (published) | Use |
|--------|-------------------|-----|
| Property Detail | $29 | Current owner, vesting, open encumbrances summary |
| Deed / document image | $45 | Certified instrument copy |
| Lien report | $95 | Recorded encumbrances |
| Full property/owner lien | $195 | + personal liens / SOS UCC / BK |
| Chain of title | $275 | Conveyance history |
| Expanded / prelim title | ~$295–375 | Underwriting-style package |
| Search by name | $75/state · $535 nationwide | All holdings for a person/entity |

**Useful for us?** Only as **exception / fraud / dispute** lookup — not portfolio overlays. Cost scales with hit volume; no match-append national plant.

**Vs peers:** [ATTOM](attom.md) / DataTree / CoreLogic = licensed bulk deed+assessor files. [County recorder DIY](county-recorder-diy.md) = free portals county-by-county (no national API).
