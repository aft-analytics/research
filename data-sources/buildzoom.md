# BuildZoom Data (now Gryd)

[buildzoomdata.com](https://www.buildzoomdata.com/) · product/pricing: [grydhq.com](https://grydhq.com/) · [pricing](https://grydhq.com/pricing)

Commercial **US** building-permit + contractor + property history dataset (rebranded **Gryd**). Claims **380M+** permits, **60M+** properties, **6M+** contractors, **2,500+** jurisdictions (~**90%** pop), **25+** years; res + commercial. Grain: **address/property** permit history + contractor licenses/activity (not geo aggregates).

**Access:** Explorer (UI) · REST API · Bulk (weekly/monthly full + incremental). Freshness marketed as daily (~70k new permits / day). Public API docs gated; data dictionary / jurisdiction index listed as coming soon.

**Pricing (Explorer, per-state tiers):** Free (2 property reports) · Core from **$150**/mo ($125 annual) · Pro from **$480**/mo ($384 annual, 1k downloads/mo) · **Premium = custom** (multi-state/national, **API + bulk**).

**vs peers:** Deeper national history than DIY city portals; vs **Shovels** — same commercial niche (Shovels ~174M permits / ~2.7k jurisdictions, clearer public docs + free API trial; Gryd claims more history/fresher daily). vs **Census BPS** — BPS is free *new residential* **place/county aggregates**, not parcel permits. vs **NYC DOB open data** — free parcel grain but **NYC-only**; Gryd is the national paid normalization layer.

**Limit:** API/bulk quote-gated for national use; coverage/fields vary by jurisdiction. Useful if we need national property-level renovation/activity overlays without stitching city portals.
