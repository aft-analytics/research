# OpenCorporates

[opencorporates.com](https://opencorporates.com/) — global legal-entity DB (~200M+ companies) from public registries; API + bulk.

**Verdict:** Useful for **cross-border / multi-jurisdiction lookup** and provenance. For **US bulk firm graph**, prefer [DIY SOS bulk](sos-bulk-by-state.md) + [GovFiles](govfiles.md) (cheaper / US-focused). Don’t buy OC as the primary national SOS plant.

| Path | Notes |
|------|--------|
| Free API | Share-alike open-data use; tiny default caps (~200 req/mo without paid) |
| Self-serve API | ~£2.25k–£12k/yr; still low call caps (500–5k/mo) — lookup, not dump |
| Enterprise bulk | SFTP by jurisdiction — quote; only if we need global normalize beyond US DIY |

**Vs peers:** GovFiles / CompanyData = US SOS commercial; OpenCorporates = broader jurisdictions + officers/filings graph, API-first. Spot checks / KYB enrichment yes; full US overlay no at self-serve tiers.
