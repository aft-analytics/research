# State open data portals (Forbes 2018 list)

[Forbes — 50+ state open data portals](https://www.forbes.com/sites/metabrown/2018/04/30/us-states-offer-information-resources-50-open-data-portals/) (Meta Brown, **Apr 2018**). Companion: [90 municipal portals](https://www.forbes.com/sites/metabrown/2018/04/29/city-governments-making-public-data-easier-to-get-90-municipal-open-data-portals/).

**Use:** starting map of state/city open-data entry points — same pattern as [Open NY](data-ny-gov.md) / [NYC](nyc-open-data.md) / [CT bulk](sos-bulk-by-state.md). Also discoverable via [data.gov](data-gov.md) harvest.

**Caveats:** list is **8+ years old** — many URLs moved or died. Mixes true catalogs (Socrata/CKAN: NY, CO, TX, MD…) with **budget/transparency** sites (e.g. AZ OpenBooks, CT transparency) and **GIS hubs** (ArcGIS). Depth uneven; not SOS entity dumps or deeds by default — search each portal for corporations, permits, parcels, assessments.
