# ATTOM

[attomdata.com](https://www.attomdata.com/) — national property plant: assessor/tax, **recorder/deeds**, mortgage, foreclosure, AVM/neighborhood. Claims ~158M+ US properties; recorder product cites 500M+ txns / ~2,690+ counties.

**Delivery:** REST Property API (30-day developer trial); bulk license; cloud incl. **Databricks Delta Sharing** (assessor, **recorder deeds**, mortgages, permits, etc. in share — scope = contract). Estated API folded into ATTOM.

**Pricing:** Contact-sales (billed by API “reports” / property returns). Property Navigator list ~$499/yr; API/bulk custom.

**Useful for us?** **Yes** — baseline for ownership / deed overlays. Peers: [property-data-vendors.md](property-data-vendors.md). DIY framing: [deeds-by-state.md](deeds-by-state.md).
